# Movie-Magic-Ticket-Booking-System
## Project Description
Movie Magic is a cloud-based movie ticket booking system designed to deliver a seamless and modern entertainment experience. The platform enables users to browse movies and events, check real-time availability, and book tickets efficiently without the limitations of traditional booking methods such as long queues and inconsistent service. The system provides an intuitive interface where users can search for movies based on location or preferences, view show timings, and select seats through an interactive layout. Real-time data handling ensures that seat availability and event information remain accurate and up-to-date, enhancing the overall user experience. Built on a scalable cloud infrastructure, the application supports multiple users simultaneously while maintaining performance and reliability. Integrated notification services provide instant booking confirmations via email, including essential details such as movie name, showtime, and seat allocation. Overall, Movie Magic streamlines the ticket booking process by combining efficiency, accessibility, and real-time interaction, making it a reliable solution for modern digital entertainment access. The system includes several key features such as a user-friendly registration and login process, the ability to browse movies and events by location and genre, real-time seat availability tracking, and an interactive seat selection interface. It ensures a fast and secure ticket booking experience while also providing instant email notifications for booking confirmations. The platform is designed to handle multiple users efficiently, making it suitable for high-demand scenarios. The technology stack used in the system includes Flask for backend development, which manages application logic and request handling. The application is hosted on AWS EC2 to ensure scalability and reliable performance. DynamoDB is used for dynamic and efficient data management, while SQLite is utilized for local database design and testing purposes. AWS SNS is integrated to handle real-time notification services, and GitHub is used for version control and project management. Overall, Movie Magic delivers an efficient, scalable, and user-friendly solution for modern movie ticket booking.
